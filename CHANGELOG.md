# Changelog

All notable changes to Ticketsmith. Versions follow [semver](https://semver.org); entries are generated by `pnpm release` from conventional commits.

## 0.7.0 — 2026-10-16

### Features

- **doctor:** show which databases accept proposed changes
- **process:** add the service-request playbook and report pending changes
- **changes:** review, approve or reject proposed changes in the terminal
- **databases:** let the agent propose changes with db_propose_change
- **database:** add the write guard, preflight and the approved-change write path

### Documentation

- document approved database changes and ADR 0023

## 0.6.0 — 2026-10-16

### Features

- **doctor:** check that Claude Code is installed and signed in
- **projects:** add deep repository analysis with project refresh repos --deep
- **process:** investigate tickets end to end with the bug playbook
- **agent:** add the agent runtime on Claude Code headless, playbooks and limits
- **security:** reveal masked values for local files, never secrets

### Fixes

- **agent:** drop the meta-schema URI that Claude Code rejects in --json-schema

### Documentation

- document agent runs, process, knowledge tools and ADR 0022

## 0.5.0 — 2026-10-16

### Features

- **doctor:** check repository access, base branches, clones and runtimes
- **repos:** add MCP tools repo_list, repo_files, repo_search, repo_read
- **projects:** add repositories integration with dedicated clones and maps

### Fixes

- **projects:** leave test files out of detected endpoints, calls and data access
- **security:** stop masking git remote URLs as emails

### Documentation

- document repositories, the repo MCP tools and ADR 0021

## 0.4.1 — 2026-10-16

- Maintenance release.

## 0.4.0 — 2026-10-16

First public release.

- **Projects** with optional, independent integrations: `project init` (guided, resumable onboarding), `status`, `refresh`, `add`, `remove`, `list`, `use`, `show`, `link`, `export`, `import`, `rename`.
- **JIRA Cloud** ticket source with scoped read-only tokens: `jira discover`, `list`, `show`; ADF converted to Markdown.
- **Databases** (MySQL 8): any number of named databases with optional groups, schema investigation, `db ask`, and a two-layer, fail-closed read guard that runs the regenerated SQL in a read-only session.
- **MCP server** (`ticketsmith mcp`, `mcp setup`): `jira_get_issue`, `jira_search`, `db_select`, `db_select_group`, `db_schema`, with masking, a session placeholder vault and a local audit log.
- `doctor` checks every configured integration.
- Claude Code plugin with the `investigate-ticket` skill; update notice for the CLI.
